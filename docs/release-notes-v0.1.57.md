# 玄览 PocketWebShell 0.1.57

本次正式版在 `0.1.56` 基础上，针对应用内检查更新弹窗交互与展示进行了系统性重构，并同步翻新了仓库文档截图。

## 版本更新弹窗重构（Markdown 原生渲染与安全滚动）

- **Markdown 原生排版渲染**：引入 `multiplatform-markdown-renderer-m3`，版本更新公告中的多级标题、强调文本、项目清单列表与行内代码均以 Material 3 原生排版优雅渲染，彻底告别原始符号文本。内置安全 `UriHandler`，严格限制外链协议与上下文跳转。
- **卡片自适应与上下安全平滑滚动**：
  - **固定双端结构**：顶部主副标题（“发现新版本”）与底部操作坞（“稍后 / 下载”）常驻可见，避免长文遮挡按键；
  - **中间自适应滚动**：卡片宽度自适应约束，中间正文区域限定在安全高度内独立垂直平滑滚动，长文本绝不溢出屏幕。
- **完整 Release 日志提取**：去除旧版本中的 400 字符限制与暴力剔除符号逻辑，由数据层直接透传 GitHub Releases 返回的完整说明。

## 视觉与文档完善

- **README 截图翻新**：将仓库 `README.md` 中两张过时的早期灰底通栏历史截图，全面替换为带有最新 **iOS Liquid Glass 悬浮毛玻璃 Dock** 的 Android 15 实机截图，与主屏及设置页保持高度一致。

## 验证与已知范围

- 全量 Gradle 单元测试通过（包含 `:core:data`、`:feature:me`、`:app` 等 304 项检查）。
- 模拟器实机验证弹窗首屏渲染、正文滑动与外链保护机制正常。
- 本正式包使用项目长期外部发布密钥签名，并随 Release 提供 SHA-256 与公开证书。

## 安装与升级

下载 `PocketWebShell-v0.1.57.apk`，最低支持 Android 10（API 29）。这是正式签名包，不是 Debug 包；同时提供 `.apk.sha256` 校验文件和 `PocketWebShell-release-cert.pem` 公开证书。后台运行仍受 Android Doze、厂商策略、内存压力和站点自身节流约束。
