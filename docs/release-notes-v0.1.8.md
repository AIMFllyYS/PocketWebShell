# 玄览 PocketWebShell 0.1.8

本版本修复主页图标两个长期顽疾，并按 Launcher3 的交互模型重构了长按手势与情境菜单。

## Highlights

- 修复首字母图标"白底无字"：网站 logo 加载失败（404/网络拦截/格式不支持）时正确回退为首字母色块；深色主题改用深底浅字高对比配色。
- 官方 logo 显示优化：等比放大铺满圆角方块、四边贴住圆角边缘，不再内缩留白边。
- 修复长按误触打开应用：图标手势重构为单通道状态机（对齐 Launcher3），长按与点击天然互斥；长按后移动超过 16dp 才进入拖拽，原地松手只弹菜单。
- 情境菜单以按压点为中心弹出，垂直方向优先向上、空间不足自动翻转，边缘自动收进屏幕内。
- 长按菜单新增：重命名、更改图标（支持本地上传，与添加流程一致）、强制刷新站点元数据；删除保留二次确认。

## Installation and verification

下载 `PocketWebShell-v0.1.8.apk`。该 APK 使用项目发布证书签名，最低支持 Android 10（API 29）。

同时提供：

- `.apk.sha256`：安装包 SHA-256；
- `PocketWebShell-release-cert.pem`：发布者公开证书，仅用于身份核对，不包含私钥。

后台运行仍受 Android Doze、厂商策略、内存压力和站点自身节流约束。
