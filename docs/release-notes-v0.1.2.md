# 玄览 PocketWebShell 0.1.2

这是继 0.1.0 之后的新一次正式发布。`versionCode` 已提升至 3，**可从 0.1.0 直接覆盖安装**，无需卸载。

本次更新围绕"统一的 Apple 风格设计系统、更清晰的设置与更新入口、命名与品牌焕新"三大方向，同时修复了一批此前在 iOS 设计对标下的对比度与排版问题。

## 品牌焕新

- 应用正式更名 **「玄览」**，配套全新的「天道·几何辉光」自适应启动图标（含深色/圆角/Monochrome 适配）。

## 设计系统统一（0.1.1）

- 新增 `core/designsystem` 统一设计系统层：完整明暗色 Token、MiSans 字阶、Shape / Spacing / Motion Token、以及共享组件（`AppCard`、`AppListRow`、`AppListDivider`、`AppSectionHeader`、`AppBadge`、`AppConfirmDialog`、`glassSurface`）。
- 内置按需子集化的 MiSans 字体（regular / medium / semibold），任何设备文字度量一致；每种能力只保留一个库，避免重复方案。
- 「我的 → 开发者选项」新增 **设计手册 Playbook**：实时预览色板、字体、圆角、间距、列表行、按钮、对话框、玻璃材质与动效规格。
- 组件与规范清单沉淀于 `docs/DESIGN.md`。

## 双主题与玻璃材质

- 新增 Apple 风格主题系统：纯白 / 纯黑基础方案、跟随系统、以及**照片壁纸模式**（自动从所选照片提取主色，入口：我的 → 外观与主题）。
- 底部导航采用 **iOS Liquid Glass 悬浮玻璃胶囊栏**（Haze 实时背景模糊 + 边缘高光）。

## 界面与导航优化

- **底部导航栏**：降低整体高度，选中项增加胶囊指示填充（纯色动画，不改变布局）。
- **浏览器顶栏精简**：复用设计系统组件，自有绘制胶囊地址栏保证文字垂直居中、不再被切割；标签计数键使用中性面 Token；书签、页内查找、新建标签移入溢出菜单。
- **「我的」页面重构**：二级菜单结构 + 分页详情页；后台会话置顶；布局滑杆改为单色轨道 + 白色滑块。

## 更新与设置入口

- **项目更新日志页**：我的 → 项目更新日志，与本仓库 `CHANGELOG.md` 保持同步。

## 对比度与视觉修复（0.1.2）

- 浅色主题重建为 iOS 分组列表标准：`#F2F2F7` 灰底承载纯白卡片，消除"粉灰污渍感"（同色对比效应）。
- 全部次级文字（`onSurfaceVariant` 等）加深至 `#55555B`，白卡对比度达 7.4:1（WCAG AAA）。
- `surfaceVariant` 加深为 `#E5E5EA`，保证图标占位与浏览器输入区在灰底上可见。
- 卡片新增 1dp `outlineVariant` 细描边（静态描边，零性能成本）。
- 深色主题卡片面统一为 iOS 分组深色 `#1C1C1E`。
- 浏览器地址栏占位文字不再被 46dp 固定高度截断；各 Material 3 色阶全部显式定义，消除卡片徽章上的偏紫问题；移除了硬编码的 Google 蓝图标配色，改用主题 Token。

## 安装与校验

下载 `PocketWebShell-v0.1.2.apk`，使用项目发布证书签名，最低支持 Android 10（API 29）。

同时提供：

- `.apk.sha256`：安装包 SHA-256；
- `PocketWebShell-release-cert.pem`：发布者公开证书，仅用于身份核对，不含私钥。

后台运行仍受 Android Doze、厂商策略、内存压力和站点自身节流约束。
