# 0.1.52 · 截图验收

日期：2026-09-14

对照版本：`versionName=0.1.52` / `versionCode=53`（开发者选项页可见）

交付形态：已安装到专用模拟器的 Debug 包 `PocketWebShell-v0.1.52-debug.apk`。截图全部来自应用真实运行，不是设计稿。

## 验证环境

- Windows，仓库 Gradle Wrapper，Android SDK 37。
- AVD：`webshell-ios-qa-api35`，Android 15 / API 35 / x86_64。
- 屏幕：1080×2400 px，density 420（约 411 dp 宽）。
- 设备上预置 GitHub、Wikipedia、YouTube 三个主屏应用；端测中另外导入了本地 HTML，并合并了一个文件夹。
- 网页加载走真实网络（Wikipedia、Bing、YouTube）；Markdown / HTML 用本机 `Download/` 文件通过 `VIEW` 打开。

本文件按产品板块收录截图。README 只放主屏、设置、拖动和文件夹四张当前视觉；更细的页面都在这里。

未覆盖：开屏黑洞动画（瞬时，adb 截不到稳定中间帧）、历史分组列表本体（菜单入口已拍到，制作应用成功弹窗反复盖住历史页）、保活分屏条（需要两个同时保活的站点壳；本次只有 YouTube 一个前台会话）。

## 1. 主屏

### 1.1 桌面网格与玻璃 Dock

![主屏](01-home.png)

固定 4 列网格。GitHub、Wikipedia、YouTube 和「添加」各占一格。底部是 iOS 风格玻璃 Dock：主页 / 添加 / 浏览 / 我的，主页为选中色。搜索胶囊浮在 Dock 上方，不参与网格测量。壁纸是浅色抽象曲线，图标圆角和标题截断与当前设计 token 一致。

### 1.2 应用长按菜单

![应用菜单](02-home-menu.png)

长按 GitHub 后弹出情境菜单：打开、复制应用链接、重命名、更改图标、强制刷新、桌面版网页、关闭后台保活、删除。删除为红色危险项。菜单是浮动卡片，Dock 和搜索仍在。

### 1.3 空白区域长按

![空白菜单](03e-menu.png)

长按主屏空白处：编辑模式、显示全部应用入口。这是进入抖动编辑态的入口之一，也是「全部应用 / App 资源库」开关。

### 1.4 编辑模式

![编辑模式](04-home-jiggle.png)

图标左上角出现选择圆点。Dock 换成编辑工具条：完成、已选 0/3、左右/上下滚动、删除、移出文件夹、移入文件夹、全选。编辑态不再弹出长按菜单，位移超过 touchSlop 即进入拖动。

### 1.5 独立拖动浮层

![拖动中](05-home-drag.png)

把 GitHub 拖到 Wikipedia 格子上。源位置留下半透明占位，浮动图标在 DragLayer 里跟随手指，不参与网格测量。底栏仍是当前编辑条，而不是早期实心底导航。

### 1.6 文件夹合并

![编辑态下的文件夹](06-home-folder.png)

悬停约 500ms 后松手，GitHub 与 Wikipedia 收进「文件夹」。添加格回到首位，YouTube 仍在第三格。编辑条已选变为 0/2。

![完成后的文件夹](07-home-folder-done.png)

点「完成」后回到普通桌面。文件夹缩略图里能看到两个应用图标，玻璃 Dock 恢复。

![打开的文件夹](08-folder-open.png)

点文件夹进入展开页：大卡片里是 GitHub 和 Wikipedia，底部有「解散文件夹」，搜索和 Dock 仍在。背景主屏被压暗。

### 1.7 App 资源库

![资源库](10-home-search.png)

点搜索胶囊进入「App 资源库」：搜索应用或网址、A–Z 侧边索引、网格/列表切换。空态文案是「未找到相关应用」（当时应用都在文件夹里，资源库按当前索引显示）。

### 1.8 制作应用之后的主屏

![带本地 HTML 的主屏](69-home-with-html.png)

从浏览菜单把本地 HTML「制作应用」后，主屏第一格出现代码块图标「本地 HTML …」，文件夹、YouTube、「添加」顺延。这是本地 HTML 与网站图标的视觉区别（Markdown 用文档 M 标，HTML 用 `<>`）。

## 2. 添加网站

### 2.1 添加页

![添加页](11-add-page.png)

标题「添加网站」。中间品牌标、网址输入（示例 github.com）、灰色「继续」、离线网页分组里的「导入本地 HTML」。底栏「添加」高亮。

### 2.2 输入网址

![已输入](12-add-typed.png)

输入 `bing.com` 后「继续」变为可点的蓝色主按钮。系统键盘打开。

### 2.3 拉取元数据

![正在获取](13-add-editor.png)

点继续后全屏进度：「正在获取站点信息…」。网络与解析在后台线程。

### 2.4 编辑草稿

![编辑器上半](13b-add-editor.png)

解析到 Bing 标题、规范化网址、候选 favicon。可改名称、网址、从照片选图标、填图标地址。右上角「添加」。

![浏览设置](13c-add-editor-settings.png)

下半段：桌面模式、深色适配、后台保活（默认开）、外链在系统浏览器打开、新窗口打开方式（跟随全局）。最下是「添加到主屏幕」。本次未保存 Bing，避免打乱主屏验收数据。

### 2.5 本地 HTML 选择器

![选择 HTML](14-html-picker.png)

自绘选择页，不是系统文件框。常用位置：下载、文档、本机存储。未授权或目录为空时提示「没有自动找到 HTML」。只显示 `.html` / `.htm`。

## 3. 浏览

### 3.1 新标签页

![新标签](15-browser.png)

地址栏、菜单、标签计数（当时 2）。正文是新标签页：收藏夹空态、最近访问空态。底栏「浏览」高亮。

### 3.2 浏览菜单

![浏览菜单](16-browser-menu.png)

当前网页：收藏本页、页内查找、桌面版、**制作应用**。个人浏览：历史、收藏夹、下载记录。界面显示：隐藏地址工具栏、收起底部导航。顶上是后退 / 前进 / 刷新 / 新标签。

同一菜单在已打开页面上再拍一版：

![带制作应用的菜单](64-html-menu.png)

桌面版可打勾。制作应用是 0.1.46 补上的入口：点过「仅查看」之后还能再加到主屏幕。

### 3.3 标签切换器

![两个标签](17-browser-tabs.png)

Markdown 文档图标的 `sample.md`（本机路径）和新标签页。底部「新标签页 / 关闭全部」。

![三个标签](17b-browser-tabs.png)

加上 Wikipedia 预览卡。标签页带关闭按钮，选中项有描边。

### 3.4 打开网页

![输入网址](18-browser-typed.png)

地址栏输入 `wikipedia.org`。

![Wikipedia](19b-browser-wikipedia.png)

站点加载后地址栏变成 `www.wikipedia.org/`。阅读时底栏按「阅读时自动收起导航」收成右下角小球。页面内容是站点自己的，不代表产品 UI。

### 3.5 站点壳与悬浮球

![YouTube 站点壳](28-siteshell-youtube.png)

从主屏点 YouTube，进入站点壳而不是浏览标签。右上角灰色玻璃球是站点壳辅助球（uiautomator 节点名「站点壳辅助球」）。没有应用顶栏。

![悬浮球菜单](29-orb-menu.png)

点辅助球：「页面选项」。工具条：后退、前进、刷新、回主屏。当前网页：收藏、桌面版。个人浏览：下载记录、隐藏辅助球、返回主屏。

0.1.45 起，若还有其它保活会话，菜单顶部会出现一条小分屏，点一下切到后台页。本次只有 YouTube 一个保活项，所以没有分屏条。开关在「我的 → 悬浮球与手势」。

### 3.6 桌面版提示

![桌面版](24-make-app.png)

切到桌面版后的说明：按电脑宽度显示，可双指缩放。取消证书错误不会离开页面（0.1.45）。

## 4. Markdown 与 HTML 预览

### 4.1 外部打开 Markdown（全屏站点壳）

![添加到主屏幕询问](57-view-md.png)

`VIEW` `PocketWebShell-notes.md`。正文已经按 Markdown 渲染（标题、列表、引用、代码块）。中间弹出「添加到主屏幕？」：把「PocketWebShell-notes」存成快捷方式。标题用的是原始文件名，不是内容提供者的垃圾段。

![全屏 Markdown](58-markdown-shell.png)

点「仅查看」后去掉对话框。没有顶部导航栏，是 0.1.48 的全屏站点壳。长按正文走系统选区。文档模式的悬浮球会关掉收藏/桌面版，只留制作应用等文档动作（本次功能开关里站点壳球为关，所以这张没有球；YouTube 那张能看到球）。

### 4.2 浏览标签里的旧 Markdown

![标签里的 MD](22-markdown-tab.png)

升级前已经打开的 `sample.md` 仍作为浏览标签：地址栏显示 `/storage/emulated/0/Download/sa…`，正文是旧稿。新的外部 Markdown 不再进浏览标签。

### 4.3 本地 HTML

![HTML 询问](62-view-html.png)

外部打开 HTML 走浏览标签。地址栏是本机路径，不是 `raw%3A` 或 `tmp-` 随机段。同样询问是否加主屏，标题用页面 `<title>`「本地 HTML 预览」。

![HTML 页面](63-html-page.png)

「仅查看」之后的标签。底栏已收起，右下角是恢复导航的小球。

![悬浮球与手势](39-me-features.png)

## 8. 已知限制

- 开屏 0.1.52 最终流程（字和粒子同时上、黑洞期间字幕保留、整层淡出）需要冷启动眼看，截图只能拍到进主页之后。
- 历史时间分组（今天 / 昨天 / 前天 / 一周内 / 一个月内 / 更早）和搜索框在 0.1.50 已落地，菜单入口见 16、64；本次点「历史」时「已添加到主屏幕」弹窗反复出现，没有进入列表页。
- 悬浮球保活分屏条需要至少两个保活站点壳。本次只有 YouTube 在跑。
- Wikipedia 首页是站点自己的捐款层，不是产品 UI。
- 模拟器 WebView 与真机厂商 WebView、通知权限、电池白名单仍要以真机为准。
