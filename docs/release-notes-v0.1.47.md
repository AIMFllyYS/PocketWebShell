# 玄览 PocketWebShell 0.1.47

本次正式版汇总自上一正式版 `0.1.34` 以来的全部迭代（`0.1.35`–`0.1.47`）。产品合同不变：单用户、全局一份登录态，不引入多账号或多 Profile。浏览器标签、桌面网站入口、直接链接和本地导入继续共享默认 WebView Profile；Cookie 与站点存储跨入口复用。`0.1.35`–`0.1.46` 仅有 debug / 合入记录，未单独发布 GitHub Release。

## 开屏

- 冷启动开屏统一为黑洞：吸积环、事件视界、光子环、坠入粒子，闪光后收成品牌标。浅色不再走白洞外爆。
- 时长约一半（约 1.1 秒 + 短暂淡出）。主页在动画前半就叠上，结尾少卡一下。开屏期间底栏不做实时模糊，也不再中途预热 WebView。

## 本地 HTML 与外部打开

- 添加页改为自绘选择页，会在下载、文档和常见聊天目录里找 HTML；没有「所有文件访问」时不再把空文件夹报成没权限。
- 微信、文件管理器等可以用玄览打开 HTML / Markdown。打开后是浏览标签，顶栏显示本机路径；同一路径再打开会回到已有标签或主屏应用。
- Markdown 加到主屏或出现在标签切换器时，使用 Markdown 文档图标（圆角文档里的 M 与下箭头）。本地 HTML 仍用代码块图标。
- 浏览菜单可把当前外部文档「制作应用」。Markdown 用应用内渲染器显示，远程图不加载。

## 站点壳与浏览

- 从主屏打开的网站使用可拖动的辅助球：贴边胶囊、点球菜单与浏览页一致。可按站选择新窗口是跳到浏览页，还是留在当前应用里覆盖打开。
- 杀进程后浏览标签条仍在。系统返回在不能后退时回到主屏，标签继续挂着。
- 电脑端按整屏宽度缩小（980），再双指捏合。证书失败点取消只关对话框，不离开页面；从不默认放行坏证书。

## 下载与存储

- http(s) 下载交给系统 DownloadManager，写到 `Download/PocketWebShell/`。全应用胶囊显示进度。
- 存储管理按站展示可核实占用，并可定向清除该站数据。清缓存会删掉网页 HTTP 缓存。

## 主屏

- 编辑收成一条底部菜单栏。图标名称单行省略。双指捏合或平行滑动进入编辑。
- 主屏应用可选择新窗口打开浏览页，或在站点壳内覆盖。

## 验证与已知范围

- 发布前运行 `testDebugUnitTest :app:assembleDebug`。
- 本正式包使用项目既有外部发布密钥签名，并随 Release 提供 SHA-256 与公开证书。
- 页内 blob 保存、系统下载入口、清缓存后登录仍在、以及 API 29–32 设备差异，仍需在设备矩阵上人工回归。

## 安装与升级

下载 `PocketWebShell-v0.1.47.apk`，最低支持 Android 10（API 29）。这是正式签名包，不是 Debug 包；同时提供 `.apk.sha256` 校验文件和 `PocketWebShell-release-cert.pem` 公开证书。后台运行仍受 Android Doze、厂商策略、内存压力和站点自身节流约束。
