# PocketWebShell 0.1.65

网页顶部避让修复与三模式设置。上一份 GitHub Release 是 0.1.64，本说明只覆盖 0.1.65。

## 网页顶部避让

- 修复部分设备网页顶部出现重复留白/白边：站点壳按 WebView 在窗口中的实际位置补足剩余顶部安全距离，系统或父容器已预留的空间不再重复叠加。
- 原生处理顶部后，清除传给网页的重复顶部安全区和自定义 CSS 顶部距离；侧边挖孔、底部手势区和键盘信息保持正常。
- 浏览标签隐藏地址栏时由网页宿主接管顶部避让，页面可向上铺满；原生地址栏和设置页保留正常安全距离。

## 新设置

- 「我的 → 浏览体验 → 网页顶部避让」：自动（推荐）、强制避让、强制不避让。
- 切换立即作用于已打开的站点壳和浏览标签，不重建 WebView、不主动刷新页面；选择会保存并随设置备份导出。

- `:app:connectedDebugAndroidTest`（`WebTopInsetInstrumentedTest`，API 35 模拟器：三模式顶部几何、CSS 安全区、WebView 复用与表单/滚动位置保留）
