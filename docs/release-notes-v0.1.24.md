# 玄览 PocketWebShell 0.1.24

这是正式上线前的最后一轮体验打磨。正式 Release 说明须在用户确认同号 Debug 构建后，按 `docs/VERSIONING.md` §5 汇总本版本与上一正式版本之间的全部变更。

## 本版本更新

- 深色模式下「我的」页「设置」标题改为 `onSurface`，不再出现黑字。
- 「我的」底栏与添加页一样叠在内容上，使用同一处磨砂玻璃，去掉选中态色块。
- 后台与通知改用圆角彩色图标；后台会话单行省略，结束前二次确认。
- 全部会话支持选择 / 全选 / 批量结束，二级页隐藏底栏并换成操作条。
- 网页加载使用统一的顶栏进度；新标签页改为收藏夹和最近访问。
- 添加页换上玄览品牌标，引导文案改为单行。
- 下拉刷新默认关闭，仅在页面到顶时生效；网站壳菜单可手动刷新。
- 开屏粒子改用 Logo 鎏金色，收束时聚合成太极环与伴星。

## 验证边界

- 已运行 `testDebugUnitTest` 与 `:app:assembleDebug`。
- 深色模式标题、底栏磨砂、会话多选、新标签页、开屏聚合和真实网站下拉刷新需真机确认。
