# 玄览 PocketWebShell 0.1.52

本次正式版汇总自上一正式版 `0.1.47` 以来的全部迭代（`0.1.48`–`0.1.52`）。产品合同不变：单用户、全局一份登录态。浏览器标签、桌面网站入口、直接链接和本地导入继续共享默认 WebView Profile。`0.1.48`–`0.1.51` 仅有 debug / 合入记录，未单独发布 GitHub Release。

## 开屏

- 冷启动按最终流程：字幕和粒子一起出现，黑洞展示期间字幕不收；播完后字幕、黑洞和遮罩同一层淡出，再进入主页。
- `0.1.48`–`0.1.51` 连续打磨了时长、卡顿和文字残留；`0.1.52` 定稿为整层一起收，不再先藏字再播黑洞。

## Markdown 与本地文件

- 打开 Markdown 改为全屏站点壳：无顶部导航栏，带与网页应用相同的悬浮球；渲染后支持手机原生长按选中。
- 文档名用原始文件名；微信等内容提供者路径拿不到名字时不强行编造。
- Markdown 文档图标左右略加宽。外部 HTML 仍走浏览标签。

## 图标

- 单文件 HTML 会使用页面里的远程 favicon 或小体积 data URI，目录里有本地图标时优先用本地。
- 收藏夹和历史左侧改为各站自己的图标，不再共用星星或地球标。
- 展示层图标兜底改为站点自己的 `/favicon.ico`。浏览页收到 touch icon 时写回历史。Room v7 为历史增加 `iconUrl`。

## 浏览历史与更新日志

- 历史按今天、昨天、前天、一周内、一个月内、更早分组，可折叠；顶部可搜索。默认先加载 20 条，下滑再加一页。
- 应用内更新日志默认先显示最近 20 条，底部「加载更多」。

## 动效与空主页

- 存储占用卡片、确认框和状态提示从细点弹簧撑开。
- 空主页不再叠「把喜欢的网站放在主屏幕」，网格里仍有添加格。

## 验证与已知范围

- 发布前运行 `testDebugUnitTest :app:assembleDebug`。
- 本正式包使用项目既有外部发布密钥签名，并随 Release 提供 SHA-256 与公开证书。
- 开屏在各厂商机上的观感、外部 Markdown 的原生长按选中、以及历史搜索的大数据量，仍需在设备上人工回归。

## 安装与升级

下载 `PocketWebShell-v0.1.52.apk`，最低支持 Android 10（API 29）。这是正式签名包，不是 Debug 包；同时提供 `.apk.sha256` 校验文件和 `PocketWebShell-release-cert.pem` 公开证书。后台运行仍受 Android Doze、厂商策略、内存压力和站点自身节流约束。
