# 性能预算（PERFORMANCE）

本文件是 PocketWebShell 渲染与交互性能的硬性预算；AGENTS.md 引用本文件。设计升级不得以突破预算为代价。

## 1. 模糊与玻璃效果

- 全屏同时存在的实时模糊 backdrop **不超过 1 处**（当前为底部导航条）。
- 模糊半径预算 ≤ 24dp 等效；禁止对整屏内容做实时模糊。
- 玻璃层不得参与布局测量，不得改变任何组件的布局边界。

## 2. 主页与手势

- 主页拖动图标、翻页手势期间：玻璃层与壁纸层不追加动画、不触发额外测量。
- 拖动视觉（悬浮图标、热点）永远不参与网格测量（与 AGENTS.md 启动台不变量一致）。
- 远程图片的固有尺寸永不决定网格几何；每个桌面单元宽高确定。

## 3. 图片与壁纸

- 壁纸加载统一走 Coil，解码与 Palette 取色在后台线程，结果缓存，不因重组重复取色。
- 壁纸按屏幕尺寸降采样加载，禁止把原图全尺寸解码到内存。

## 4. 平台降级

- API 33+：AGSL 实时模糊；API 31–32：RenderEffect；API 29–30：自动降级为半透明 scrim。
- 降级只影响视觉，不阻塞任何功能；禁止为了视觉效果提升 minSdk。

## 5. 重组纪律

- 底栏、壁纸等全局层读取状态时使用生命周期感知收集，避免因高频状态（如拖动偏移）触发大范围重组。
- 动画优先使用 `graphicsLayer` / `animateDpAsState` 等不改布局的手段。
