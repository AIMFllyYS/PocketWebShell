# 玄览 PocketWebShell 0.1.63

本次正式版补齐通用网站壳对明文 HTTP 的访问能力：系统不再直接拦截 `http://` 主文档，加载前用现有确认弹窗说明连接未加密，用户可退出或继续访问。上一份正式版是 0.1.62，中间没有未发布的 debug 号码需要汇总。

## 顶层 HTTP 导航

- 应用网络安全配置允许明文 HTTP，校园移动站等 `http://` 入口（例如被重定向到 HTTP 移动域的站点）可以打开，而不再出现 `ERR_CLEARTEXT_NOT_PERMITTED`。
- 主框架 `http://` 导航（地址栏、应用内加载、页内重定向）会先弹出确认框：说明流量可能被窥看或改写，主按钮「继续访问」，次按钮「退出」。
- 同一浏览会话内，同一主机确认一次后不再反复打断。
- 继续后页面正常加载；浏览标签地址栏与站点壳顶栏常驻「不安全」，并有一次短提示。退出则取消这次导航。
- HTTPS 页面里的 HTTP 脚本/接口仍按混合内容拦截；证书错误路径不变，不会静默放行无效证书。
- 普通 HTTP 站点的网络失败不再误报「请升级 HTTPS」。

## 验证与已知范围

- 全量 Gradle 单元测试与 debug 构建通过；新增明文闸门单测。
- 真机验收：`http://hust.m.humanyun.com/` 弹出确认后继续可进入登录页。
- 本正式包使用项目长期外部发布密钥签名，并随 Release 提供 SHA-256 与公开证书。

## 安装与升级

下载 `PocketWebShell-v0.1.63.apk`，最低支持 Android 10（API 29）。这是正式签名包，不是 Debug 包；同时提供 `.apk.sha256` 校验文件和 `PocketWebShell-release-cert.pem` 公开证书。后台运行仍受 Android Doze、厂商策略、内存压力和站点自身节流约束。
