# 玄览 PocketWebShell 0.1.26

这是「单用户全局登录态」系统性收口迭代：把浏览器壳对照普通浏览器的行为差距按 P0/P1 优先级分四批修掉，不引入任何多账号/多 Profile 机制。正式 Release 说明须在用户确认同号 Debug 构建后，按 `docs/VERSIONING.md` §5 汇总本版本与上一正式版本之间的全部变更。

## 本版本更新

- 主页收藏星标不再改变外链策略；只有站点编辑器里显式的「外链在系统浏览器打开」开关才会把跨域链接交给系统浏览器。
- 网站壳（保存的站点/直链）的 `window.open`/`target=_blank` 总是分配一个真实的、共享同一份默认登录态的池化会话，不再复用当前页面的 WebView；弹出的登录/OAuth 窗口交给浏览器标签承接。
- 已离开本地导入页面的会话不能再让同页 iframe/脚本继续读取 `/local/<appId>/` 下的文件——本地文件访问权跟随当前主文档 origin，不跟随会话曾经持有的能力。
- 存储管理详情页去掉误导的「按站清理」；「清除全部网站数据」现在会彻底销毁全部会话（不留返回栈快照）并清理 IndexedDB / Service Worker / Cache Storage 等站点数据目录，退出登录更彻底。
- 「结束后台会话」会真正挂起会话渲染并在无会话时停止前台服务，不再只是从保活列表摘除。
    10|- 网页 JS 对话框只发给当前可见宿主，不再落回持久 session listener 的默认实现；关闭定位提示不再连带取消其他等待中的请求。
- 浏览器切标签时加载进度条不再串台；起始页/空标签页不再被悬浮 Dock 遮住。
- 站点壳首帧不会用尚未读完的下拉刷新设置覆盖已生效配置；直接链接现在也读取下拉刷新设置；Blob 下载 token 失配也会安全解除保护。

## 验证边界

- 已运行 `testDebugUnitTest` 与 `:app:assembleDebug`。
- 无设备环境：跨入口（桌面/浏览器标签/直链）登录共享、收藏站 OAuth 弹窗接管、本地导入越权拒绝、退出登录后重新登录、结束会话后台通知消失，均为手测清单，未在本轮真机验证。
