# 玄览 PocketWebShell 0.1.26

本次正式版汇总自上一正式版 `0.1.22` 以来的全部迭代（`0.1.23`–`0.1.26`）。产品合同不变：单用户、全局一份登录态，不引入多账号或多 Profile。浏览器标签、桌面网站入口、直接链接和本地导入继续共享默认 WebView Profile；Cookie 与站点存储跨入口复用。

## 登录态与真实窗口

- 网站壳（保存的站点 / 直链）的 `window.open` / `target=_blank` 现在总是分配真实的池化浏览器会话，与其它入口共享同一份默认登录态，不再复用当前页面的 WebView。弹出的登录 / OAuth 窗口交给浏览器标签承接。
- 主页收藏星标不再改变外链策略；只有站点编辑器里显式的「外链在系统浏览器打开」开关才会把跨域链接交给系统浏览器。
- 后台标签创建的真实窗口会立即绑定持久 session listener，避免出现无人认领的 WebView。

## 站点数据与会话生命周期

- 存储管理新增「清除全部网站数据」确认流：关闭全部会话后清除 Cookie 与网站存储，并明确提示会退出登录。
- 「清除全部网站数据」会彻底销毁会话（不留返回栈快照），并清理 IndexedDB / Service Worker / Cache Storage 等站点数据目录。
- 共享默认 Profile 下不再提供会误导的「按站清理」——本产品没有可安全单独清理的站点边界。
- 「结束后台会话」会真正挂起会话渲染，并在无会话时停止前台服务，不再只是从保活列表摘除。全部会话页支持选择、全选和批量结束。

## 本地资源与安全边界

- 本地导入资源的读取权限绑定到当前会话的 `appId`；浏览器 / 直链会话不能读取任意 `/local/<appId>/` 文件，编码后的路径穿越也会被拒绝。
- 已离开本地导入页面的会话，不能再让同页 iframe / 脚本继续读取该目录——本地文件访问权跟随当前主文档 origin，不跟随会话曾经持有的能力。
- 应用级 WebView 调起外部协议时补上 `FLAG_ACTIVITY_NEW_TASK`；`intent:` URI 不允许指定显式 package / component / selector。
- Renderer 崩溃自动恢复最多连续尝试一次；替代 WebView 立即崩溃时进入可观察失败状态，不再无限重建。
- HTTP 主文档错误会结束当前会话的加载状态。

## 浏览器体验

- 网页 `alert` / `confirm` / `prompt` / `beforeunload` 由应用对话框承接，只发给当前可见宿主；后台标签立即完成回调，避免登录或支付页静默卡住。
- 关闭地理定位提示不再连带取消其他正在等待的文件选择、权限或 JS 对话框。
- 浏览与网站壳统一使用顶栏加载进度；切标签时进度条不再串台。新标签页改为收藏夹 + 最近访问。
- 设置中新增「下拉刷新网页」开关，默认关闭；仅在页面已到顶部且用户打开开关时拦截手势。网站壳菜单提供手动刷新。打开网站壳的第一帧不会用尚未读完的设置覆盖已生效配置；直接链接也会读取该设置。
- 修复 Blob 下载结果解析；下载读取期间保护会话，避免被池淘汰。回调 token 不匹配时也会安全解除保护。

## 界面

- 「我的」与「添加」页大标题在深色模式下不再出现黑字；「我的」底栏改为与内容叠层的悬浮玻璃。
- 添加页改用玄览品牌标，并缩短引导文案避免换行。浏览器起始页 / 空标签页不再被悬浮 Dock 遮住底部。
- 开屏粒子改为 Logo 同色的鎏金星轨，收束时聚合成太极环与伴星。
- 后台与通知改用圆角彩色图标；后台会话标题与网址默认单行省略。

## 验证与已知范围

- 发布前在 `dev` 运行 `testDebugUnitTest`：198 项通过，0 失败，0 跳过；`:app:assembleDebug` 通过。
- 本正式包使用项目既有外部发布密钥签名，并随 Release 提供 SHA-256 与公开证书。
- 跨入口登录共享、OAuth 弹窗接管、本地导入越权拒绝、退出登录后重新登录、真实站点 JS 对话框、下载与 renderer 崩溃恢复，以及 API 29–32 设备差异，仍需在设备矩阵上人工回归。

## 安装与升级

下载 `PocketWebShell-v0.1.26.apk`，最低支持 Android 10（API 29）。这是正式签名包，不是 Debug 包；同时提供 `.apk.sha256` 校验文件和 `PocketWebShell-release-cert.pem` 公开证书。后台运行仍受 Android Doze、厂商策略、内存压力和站点自身节流约束。
