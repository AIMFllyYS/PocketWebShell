# 玄览 PocketWebShell 0.1.13

本版本聚合 0.1.10 – 0.1.13 四个迭代（0.1.10 – 0.1.12 此前仅以 debug 包交付，未单独登上 Releases 页）。三条主线：应用内日志与崩溃捕获、桌面交互大版本（全部应用抽屉、上下滚动模式、边缘悬停开新屏）、拖拽会话架构级修复。

## Highlights

### 拖拽与翻页（0.1.11 – 0.1.13 多轮修复，合并陈述）

- 修复"拖到屏幕边缘开新页没反应"的根因：拖拽跟踪协程原先挂在被拖图标的 composable 上，翻页后源页被移出组合导致协程取消、状态清零、临时页回弹。拖拽会话主循环上移到根级容器（对齐 Launcher3 DragController 分层），翻页/开新屏后源 cell 被 dispose 不再影响会话。
- 拖拽停在末屏右缘或首屏左缘约 900ms 插入临时空白页并翻过去，可直接落子；松手未落子则临时页自动裁掉。落子到左缘新页时其余页面整体后移一页。
- 边缘悬停翻页改为单 snapshotFlow 状态机，连续/二次翻页可靠触发。

### 桌面交互

- 「全部应用」浮动入口与抽屉：主屏右下角可拖动半透明入口（位置持久化、可隐藏），抽屉按标题拼音首字母 A→Z、# 殿后分区，右侧字母索引条支持点按与按住滑动连续跳转。
- 桌面滑动模式（主页布局 → 桌面滑动）：左右翻页（默认）与上下滚动可切换，共享同一数据模型与拖拽不变量。
- 编辑（jiggle）模式即按即拖：位移超过触摸阈值直接进入拖拽，原地松手为勾选切换，全程不弹长按菜单。
- 空白处长按菜单：进入编辑模式、隐藏/显示全部应用入口。

### 日志与诊断（0.1.10）

- 应用内日志持久化：INFO/WARN/ERROR 级别经 Room 落盘（v2→v3 显式迁移），进程结束后仍可回看；日志查看页倒序分页加载、标签过滤、红色清空按钮（二次确认）。
- 崩溃捕获：未捕获异常的堆栈在进程死亡前同步写入数据库，再转发默认 handler。
- 监测点覆盖页面加载各阶段、SSL 错误（仅 host）、标签与会话启停、前台服务启停、添加网站成败原因、启动版本号。

### 工程质量

- feature/home 交互层拆分：HomeInteractionState（集中会话状态持有者）与 HomeGestures（手势检测、根级拖拽会话、捏合编辑、边缘状态机），HomeScreen 只保留组合根。
- 新增主页手势仪表化测试（真实 MotionEvent 注入 + Room 落库断言）7 条验收路径。

## Installation and verification

下载 `PocketWebShell-v0.1.13.apk`。该 APK 使用项目发布证书签名，最低支持 Android 10（API 29）。

同时提供：

- `.apk.sha256`：安装包 SHA-256；
- `PocketWebShell-release-cert.pem`：发布者公开证书，仅用于身份核对，不包含私钥。

后台运行仍受 Android Doze、厂商策略、内存压力和站点自身节流约束。
