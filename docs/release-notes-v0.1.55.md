# 玄览 PocketWebShell 0.1.55

本次正式版汇总自上一正式版 `0.1.52` 以来的全部迭代（`0.1.53`–`0.1.55`）。产品合同不变：单用户、全局一份登录态。浏览器标签、桌面网站入口、直接链接和本地导入继续共享默认 WebView Profile。`0.1.53` 与 `0.1.54` 仅有 debug / 合入记录，未单独发布 GitHub Release。

## 开屏启动全面重构

- **浅色白洞与深色黑洞天体动效**：Android 12+ 系统启动窗移除深色底框，分别采用浅色白洞与深色黑洞透明矢量微标；Compose 动态开屏升级为耀金白洞与深空黑洞引力动效，引入衬线艺术字与字距光引展开，60/120fps 全程硬件加速无缝淡出。
- **双层并行预热流水线**：底层的 `MainScaffold` 在开屏遮罩下立即异步静默完成初次布局与数据读取（期间禁用实时毛玻璃），开屏淡出时主线程无冲突，首帧平滑自然。

## 本地 HTML 全路径深度扫描

- **全盘多级子目录覆盖**：修复 Android 11+ OEM 存储卷回退，全面递归扫描 `Download` 根目录及其任意下级子目录（浏览器下载、各类网盘、聊天软件等）与公共文档目录。
- **高性能与超时保护**：采用后台并发协程扫描，支持最大 5 层深度遍历与 3.5s 超时中断兜底，在百毫秒内完成渲染。

## 桌面编辑多选操作栏 iOS 化

- **操作栏职责解耦**：将未选中状态下的「桌面排版 / 左右-上下翻页」与多选状态彻底分离，多选时底栏聚焦于批量操作。
- **杜绝文字截断**：多选状态下重构为清晰的计数胶囊（「已选 N / M」）与对称宽幅操作坞（「删除」与「移入文件夹」/「移出文件夹」）；多选包含不同归属时智能折叠为「文件夹 ▾」二级下拉菜单（`DropdownMenu`），空间充裕，绝无文字截断与省略号。

## 应用内检查更新

- **GitHub Release 官方更新源**：在「我的 → 关于」新增「检查新版本」，对照 GitHub `releases/latest` 的 tag（`v<versionName>`）判断是否有正式版可更新，不引入自建后端。
- **交互规范**：已是最新行尾显示说明并弹窗提示；发现新版本时弹出确认框，确认后跳转至 GitHub APK 下载链接。

## 验证与已知范围

- 发布前全量运行 `.\gradlew.bat testDebugUnitTest :app:assembleDebug` 全部通过。
- 本正式包使用项目既有外部发布密钥签名，并随 Release 提供 SHA-256 与公开证书。
- 开屏在各厂商机上的观感、外部 Markdown 原生长按选中及本地 HTML 深度扫描，已在 Android 15 (API 35) 模拟器上完整实机验证。

## 安装与升级

下载 `PocketWebShell-v0.1.55.apk`，最低支持 Android 10（API 29）。这是正式签名包，不是 Debug 包；同时提供 `.apk.sha256` 校验文件和 `PocketWebShell-release-cert.pem` 公开证书。后台运行仍受 Android Doze、厂商策略、内存压力和站点自身节流约束。
