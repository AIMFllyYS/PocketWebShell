# 玄览 PocketWebShell 0.1.16

这一版带来更安心的文件夹管理与链接分享，并把后台会话收敛成可统一管理的列表；同时恢复了网站图标抓取、修复深色模式与浏览闪烁问题。本次更新覆盖自上一个正式版 **0.1.14** 以来的全部变化（含仅以调试包交付的 0.1.15）。

## 更安心的桌面管理（0.1.16）

- 解散文件夹新增二次确认弹窗：主页长按菜单与文件夹展开页的「解散文件夹」都会先弹确认，取消不产生任何变化；确认后成员移回主屏幕，应用本身不会被删除。
- 长按应用 Logo 的情境菜单新增「复制应用链接」，一键把站点网址写入剪贴板并弹出提示。
- 设置页「后台会话」最多展示前 3 条；更多时出现「全部会话」入口，进入独立页面统一查看与逐条结束全部保活会话。

## 界面清理与浏览器体验（0.1.15）

- 页面层统一表单、图标、选择行、弹窗与设置分组，移除旧控件与重复实现；Playbook 聚合各模块真实生产组件做隔离演示。
- 设置 → 外观与主题新增 MiSans、系统字体、Noto Sans SC 与 90%–130% 界面字号；只影响应用界面，不覆盖网站自身缩放。
- 浏览器顶部收敛为菜单、地址、标签的一行工具栏；进入网页、切换标签或页内导航时，底部导航立即收成玻璃小球（不再依赖滚动检测），小球支持边缘停靠，点击召回完整导航。
- 恢复添加网址时的站点图标发现：抓取的网站图标重新作为应用 Logo 显示，无图标站点仍回退为首字符。
- 修复深色模式下浏览器菜单按钮发灰难辨、浏览网页时内容区域闪烁的问题；闪烁根因是底部 Dock 对 WebView 的逐帧实时模糊采样，已改为静态玻璃材质。
- 修正 WebView 宿主安全区、会话监听与原生视图绑定，回调严格按会话归属更新对应标签页。

## 验证

101 项单元测试通过；Android 15 模拟器 17 项端侧回归全部通过；三个新功能均在模拟器完成手动冒烟（复制链接写入剪贴板、解散确认取消/确认两条路径、会话列表 3 条收敛与全部页逐条结束）。Lint 无新增错误。

这些结果不替代所有厂商真机、API 29–32 降级路径或后台行为的硬件验证。Android/Haze 的材质也不等同于 Apple 私有的 Liquid Glass 光学引擎。

## 下载与校验

下载 **PocketWebShell-v0.1.16.apk**，最低支持 Android 10（API 29）。本包使用项目既有的正式发布证书签名，不是 Debug 包。

同时提供 `.apk.sha256` 校验文件与 `PocketWebShell-release-cert.pem` 发布者公开证书。公开证书不包含私钥。

后台运行仍受 Android Doze、厂商策略、内存压力与网站自身节流限制；不会承诺永久保活。
