# 玄览 PocketWebShell 0.1.7

本版本聚焦浏览器引擎集成层的系统性修复，并包含 0.1.3–0.1.6 的桌面与设置体验更新（首次发布到 GitHub）。

## Highlights

- 修复标签页串台：标题/进度/返回状态改为按标签隔离存储，WebView 回调按会话归属写回，后台标签的加载结果不再丢失。
- 修复会话淘汰错乱：WebView 池改为真 LRU 并保护激活标签不被销毁；被淘汰会话的返回栈可在重建时恢复。
- 登录态打通：浏览器标签统一使用共享 Profile，Cookie/Token 跨标签共享；网页应用壳保持独立隔离。
- 站点兼容性加固：移动模式改用标准 Chrome 移动 UA（不再暴露 WebView `wv` 标记），改善部分站点（登录、移动站）的可用性。
- 修复沉浸壳新窗口遗留孤儿会话、关闭标签后资源未清理等泄漏问题。
- 桌面自由摆放：拖动落点即真实网格位，支持交换、文件夹解散按位填充（可在设置中切回自动整理）。
- 桌面编辑模式（双指捏合进入、抖动图标、多选）、HyperOS 风格全屏文件夹页。
- 新增开发者中心（应用/WebView/设备信息、内存日志查看器）与自定义应用图标上传。
- 统一动效系统与 iOS 风格锚点上下文菜单。

引擎诊断与选型决策见仓库 `docs/ENGINE.md`。

## Installation and verification

下载 `PocketWebShell-v0.1.7.apk`。该 APK 使用项目发布证书签名，最低支持 Android 10（API 29）。

同时提供：

- `.apk.sha256`：安装包 SHA-256；
- `PocketWebShell-release-cert.pem`：发布者公开证书，仅用于身份核对，不包含私钥。

后台运行仍受 Android Doze、厂商策略、内存压力和站点自身节流约束。
