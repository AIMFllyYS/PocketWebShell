# 玄览 PocketWebShell 0.1.33

本次正式版汇总自上一正式版 `0.1.26` 以来的全部迭代（`0.1.27`–`0.1.33`）。产品合同不变：单用户、全局一份登录态，不引入多账号或多 Profile。浏览器标签、桌面网站入口、直接链接和本地导入继续共享默认 WebView Profile；Cookie 与站点存储跨入口复用。

## 站点壳辅助球

- 从主屏打开的网站不再钉一颗只能刷新的右上角按钮，改为可拖动的辅助球。「我的 → 浏览体验」可关闭；浏览标签页不加这颗球。
- 贴边时收成短胶囊，中间是竖直的线，不是斜杠。点按后到屏幕中间变成玻璃圆球；滑向左或右再吸回对应边缘。
- 点球菜单与浏览页一致：横向前进、后退、刷新，竖向回主屏、收藏、桌面版、下载记录。没有「添加」。无法收藏时用确认弹窗说明原因。
- 关闭再打开「站点壳悬浮球」会回到右上角，不再沿用可能卡住的旧位置。

## 下载

- http(s) 下载交给系统 DownloadManager，写到公共 `Download/PocketWebShell/`，杀进程后仍继续。
- 全应用右侧胶囊显示进度和路径；完成后从左下角弹出卡片，按文件夹 → 系统下载页 → 打开文件 → 分享的顺序交给系统应用。
- 页内保存不再只靠跳转新网址：blob 改成分块读取，避开 512KB Binder 上限；带常见文件后缀的主框架链接交给下载管理器，而不是在网页里打不开。
- 浏览菜单和站点壳菜单可打开下载记录，支持查看路径并定向删除。

## 存储与日志

- 存储管理按共享 Default Profile 与 `cache/WebView` HTTP 缓存记账，不再把网站数据或 HTTP 缓存算成 0B /「应用与其他」。按站一行标明「共享存储」。
- 头条占用使用系统 `dataBytes + cacheBytes`；系统为 0 时回退磁盘遍历。进入存储页或回到前台会重新扫描。
- 清缓存会删除 `cache/WebView/`（含 HTTP Cache），并在关会话前对活动 WebView 调用 `clearCache(true)`。登录状态保留。
- 「清除全部网站数据」补删 `Network/`、`Storage/`、`Shared Storage/`，会退出所有网站登录；主页网站列表仍在。
- 清理缓存时一并清理应用内日志；概览单独列出日志占用。诊断日志写 host / 文件名 / 原因，不含 Cookie 或完整网址。

## 浏览与主屏

- 站点壳弹出的 `window.open` / `target=_blank` 按独立会话交给完整浏览标签，不再用 opener 的网址盖掉登录或 OAuth；领养后展开浏览底栏。
- 打开主页文件夹时不再先闪一帧空壁纸。桌面版网页支持内置捏合缩放。收藏夹与历史里的网址默认最多两行。
- 添加页与浏览空态统一为可着色的玄览黑洞标。

## 验证与已知范围

- 发布前在功能分支运行 `testDebugUnitTest :app:assembleDebug`，通过后用户确认同号 debug 包 `0.1.33`（`versionCode` 34）。
- 本正式包使用项目既有外部发布密钥签名，并随 Release 提供 SHA-256 与公开证书。
- 页内 blob 保存、系统下载入口、清缓存后登录仍在、以及 API 29–32 设备差异，仍需在设备矩阵上人工回归。

## 安装与升级

下载 `PocketWebShell-v0.1.33.apk`，最低支持 Android 10（API 29）。这是正式签名包，不是 Debug 包；同时提供 `.apk.sha256` 校验文件和 `PocketWebShell-release-cert.pem` 公开证书。后台运行仍受 Android Doze、厂商策略、内存压力和站点自身节流约束。
