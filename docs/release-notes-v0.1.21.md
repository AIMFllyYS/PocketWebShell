# 玄览 PocketWebShell 0.1.21

这一版把应用从「桌面整理工具」推进为「可运维的网站工作台」：新增按网站的存储统计与缓存清理、三档数据备份导出与 `.pws` 导入；桌面文件夹支持重命名与内部拖拽排序；「全部应用」资源库增加列表视图与排序切换；开屏动画重做为一小片星河的收束演出。本次更新覆盖自上一个正式版 **0.1.16** 以来的全部变化（含仅以调试包交付的 0.1.17 至 0.1.20）。

## 数据管家：存储与备份（0.1.18 – 0.1.19）

- **存储管理**（我的 → 数据与存储）：基于每个网站的独立 WebView Profile 实现真实按站占用统计；顶部概览展示已统计占用、可清理缓存与互斥不重复的三分类分段占用条；网站列表支持占用/名称排序与搜索；进入网站详情可清理缓存（只删 Cache/Code Cache/GPUCache，保留登录相关数据），也可一键清理全部可清理缓存；运行中的会话先询问再清理，结果按清理前后实测反馈。
- **数据管理**：三种导出方式——仅网址（追加导入，全新 id、重名自动编号）、网址+必要数据（原位置恢复，位置冲突或结构无效则整次拒绝）、全量·实验性（含可迁移运行数据，导入后设置需单独确认才应用）；导出完成直接调起系统分享面板，并弹出成功对话框展示文件名、大小与路径；导出文件同步写入系统「下载/PocketWebShell/」目录。
- **文件夹分享**：主页长按文件夹菜单新增「分享文件夹」，导出 `.pws`（zip 容器 + 备份清单）经系统分享发送；接收方从数据管理导入，文件夹作为整体追加、内部顺序保留。
- **修复**：存储统计可能全部显示 0 的问题——占用总览改用与系统设置一致的 `StorageStatsManager` 数据源（磁盘遍历作为回退）；独立 Profile 设置失败不再静默，避免站点数据落回共享 Profile 导致按站统计为 0。

## 桌面与文件夹增强（0.1.17）

- 文件夹支持重命名：展开页顶部标题直接点击改名，长按文件夹菜单同步新增「重命名」；文件夹名持久化在成员行上（Room v3 → v4 新增 `folderName`/`folderCellIndex`，存量数据不动）。
- 文件夹内长按成员图标可拖拽排序：跟手浮动图标层不参与测量、注册点不跳变、目标槽位高亮，松手落子并持久化；拖拽期间禁用翻页手势。
- 文件夹展开/收起改为显式动画（遮罩淡入 + 面板缩放淡入 380ms，退场 240ms），替代原先的系统默认瞬时切换。

## 全部应用资源库（0.1.20 – 0.1.21）

- 右上角新增视图选择：字母分区网格（原有默认）、列表 · 按首字母、列表 · 按时间三种视图任意切换；列表视图采用小图标 + 完整应用名称的整行布局，应用多时更易定位；按时间排序时最新添加的排在最前。
- 按首字母的列表保留分区头与右侧字母索引条；按时间的列表不显示索引条；切换视图或搜索自动回到列表顶部。
- 修复深色模式下页面文字为黑色导致不可见的问题；视图切换按钮采用全局 Rounded 图标规范并固定在最右上角，深色模式下为浅色。

## 开屏动画（0.1.17 → 0.1.21 演进）

- 冷启动开屏重做为「小星河」演出：文案先行（淡入 + 字距收紧 + 轻微上浮），随后下方一弯星河把局部粒子缓缓吸入核心——浅色主题为暖金白洞绽放，深色主题为蓝紫黑洞（事件视界、光子环、多普勒不对称的吸积弧、椭圆轨道）之上点缀闪烁星尘。
- 单 Canvas 绘制、无实时模糊；相比旧版下调粒子数与辉光层数。存在保持中的浏览会话或经 URL 直达启动时跳过开屏，回到网页零打扰。

## 验证

- 全模块 `testDebugUnitTest` 与 `:app:assembleDebug` 通过；本区间新增 54 项单元测试（备份编解码/导入规划/重名编号 34 项、存储统计与分类 18 项、全部应用时间序索引 2 项）。
- 0.1.21 debug 构建（versionCode 22）已按版本规则完成用户真机验收，正式包与验收包同号。
- 以下路径以 debug 验收与单测为准，未逐一在所有厂商真机复验：系统分享面板实际弹出、按站统计真机数值、开屏动画观感。

这些结果不替代所有厂商真机、API 29–32 降级路径或后台行为的硬件验证。后台运行仍受 Android Doze、厂商策略、内存压力与网站自身节流限制；不会承诺永久保活。

## 下载与校验

下载 **PocketWebShell-v0.1.21.apk**，最低支持 Android 10（API 29）。本包使用项目既有的正式发布证书签名，不是 Debug 包。

同时提供 `.apk.sha256` 校验文件与 `PocketWebShell-release-cert.pem` 发布者公开证书。公开证书不包含私钥。

从 0.1.16 升级可直接覆盖安装；更早版本请先确认 versionCode 不低于本包后再覆盖。
