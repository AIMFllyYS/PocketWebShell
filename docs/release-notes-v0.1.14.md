# 玄览 PocketWebShell 0.1.14

这一版，把网页桌面、玻璃 Dock、文件夹、设置和浏览器统一为 iOS 风格的原生体验，同时整理页面层的状态与渲染边界。本次更新覆盖自上一个正式版 **0.1.13** 以来的全部变化。

## 更完整的网页桌面

- 全屏静态流线壁纸，配合四图标悬浮 Dock、白色阴影标题与紧凑搜索胶囊；照片壁纸继续支持。
- 文件夹采用九宫格预览与分页展开，半透明面板覆盖完整屏幕；修正背景图标透出和透明图标中的矩形阴影。
- 菜单改为左文字、右图标的纵向列表，删除操作红色置底。
- 网格根据实际宽高和字体缩放计算，保留固定容量、稀疏自由摆放、跨页拖拽及纵向滚动。
- 搜索胶囊可按标题或 URL 查找应用；未保存过显隐设置的用户默认关闭旧浮动入口，已有设置不变。

## 统一的功能页面

- 分组设置、固定返回导航、绿色开关与添加网站页面统一呈现。
- 浏览器地址栏与操作区分行布局，紧凑屏仍可到达返回、前进、新标签与标签切换器。
- 长 URL 不再绘制到按钮区域，失焦后以省略号展示；空标签状态按返回可以回到主页。

## 更克制的渲染开销

- 全应用仅 Dock 保留一处实时 Haze 模糊，半径固定为 20dp；其余玻璃浮层使用静态材质。
- 非编辑态不挂载抖动动画；编辑时使用共享时钟，拖拽视觉继续独立于网格测量。
- 主题只订阅外观字段，资源库拼音索引在后台构建，设置滑杆松手后才保存。
- 照片取色按最长边降采样、及时回收临时位图，并修正切换/清除照片后的旧强调色残留。
- 修正打开全屏网站后的页面保存状态丢失，以及拖拽取消后迟到回调重建目标的问题。

## 验证

62 项单元测试通过；Android 15 模拟器标准屏与 320dp / 130% 字体分别通过 13 项端侧回归；Lint 为 0 错误、21 条现有警告。覆盖拖拽、新建页面、文件夹、主题、资源库和浏览器双标签。

这些结果不替代所有厂商真机、API 29–32 降级路径或后台行为的硬件验证。Android/Haze 的材质也不等同于 Apple 私有的 Liquid Glass 光学引擎。

## 下载与校验

下载 **PocketWebShell-v0.1.14.apk**，最低支持 Android 10（API 29）。本包使用项目既有的正式发布证书签名，不是 Debug 包。

同时提供 `.apk.sha256` 校验文件与 `PocketWebShell-release-cert.pem` 发布者公开证书。公开证书不包含私钥。

后台运行仍受 Android Doze、厂商策略、内存压力与网站自身节流限制；不会承诺永久保活。
