# 玄览个人信息处理规则

**版本：** 1.0  
**生效日期：** 2026-09-20  
**适用范围：** Android 应用「玄览」（PocketWebShell）、官网 https://xuanlan.1037solo.com ，以及 GitHub 仓库 AIMFllyYS/PocketWebShell 中由维护者运营的项目页。

本文说明维护者如何处理与你有关的信息。它**不是**开源许可，也**不是**云服务合同。代码的复制与再分发条件见仓库根目录 [LICENSE](https://github.com/AIMFllyYS/PocketWebShell/blob/dev/LICENSE)（GPL-3.0-or-later）。

本文是研究与产品对照后的公开说明，**不是法律意见**。

## 1. 我们是谁

处理者是 **PocketWebShell / 玄览项目维护者**。玄览是 1037Solo 生态的挂载开源项目。

联系方式（请不要在公开 Issue 里粘贴 Cookie、密码或完整浏览记录）：

- 功能、使用与权利请求：[GitHub Issues](https://github.com/AIMFllyYS/PocketWebShell/issues)
- 安全漏洞：按 [SECURITY.md](https://github.com/AIMFllyYS/PocketWebShell/blob/dev/SECURITY.md) 私下报告
- 源码与许可全文：https://github.com/AIMFllyYS/PocketWebShell

维护者**不运营**玄览用户账号，也**不把**你的浏览历史、Cookie、密码同步到维护者自己的服务器。

## 2. 请先分清三层关系

1. **本应用 / 维护者：** 在你的手机上保存桌面布局、站点入口、浏览记录和 WebView 站点数据；在你主动操作时，向 GitHub 查询正式版，或向你填写的网址请求公开页面以读取标题和图标。
2. **你打开的网站：** 登录、Cookie、统计、支付、摄像头等，由**该网站及其第三方**按其自己的规则处理。玄览不是那些网站的运营者。
3. **GitHub 等基础设施：** 检查更新、下载安装包、访问仓库时，请求会到达 GitHub。GitHub 可能处理 IP、User-Agent、时间等，详见 GitHub 的隐私声明。

## 3. 本机处理（默认不出维护者服务器）

| 种类 | 目的 | 保存期限 | 你怎么处理 |
|---|---|---|---|
| 站点入口（网址、名称、图标、桌面位置、文件夹） | 把网站放在主屏上使用 | 你删除该入口或卸载应用之前 | 主屏删除；卸载即删除本机副本 |
| 浏览标签、历史、WebView Cookie / 网站存储 | 打开网页、保持登录态 | 同上；也可在「存储管理」按站点清除 | 设置 → 存储管理 |
| 布局、主题、字体、手势开关 | 记住你的显示与操作偏好 | 卸载或恢复默认之前 | 设置页修改 |
| 应用日志（环缓冲） | 排查显示、引擎和手势问题 | 容量有限，可手动清空 | 开发者选项 → 日志 |
| 本机导入的 HTML / 外部打开的 Markdown 临时副本 | 离线页或系统分享打开 | 你删除或卸载之前 | 存储管理 / 卸载 |

工程纪律：日志**不得**记录 Cookie、密码、完整查询串或签名材料。

Android 系统备份（`allowBackup`）若被你或设备厂商打开，系统可能把应用数据拷进你的设备备份。这不是维护者收集，但是本机数据可能因此离开手机。可在系统设置中关闭该应用的备份。

## 4. 会离开本机的处理

基本浏览功能（打开已保存的入口、在地址栏输入网址访问）按浏览器类应用的常见口径，**不依赖**下列可关闭或可拒绝的能力。拒绝检查更新、通知、定位、相机、麦克风或「所有文件」权限，不应导致你无法使用已经保存的本地入口。

### 4.1 打开网页

WebView 会按你的导航向目标站点发请求。站点及其嵌入的脚本、统计、登录服务由他们处理。维护者看不到这些会话内容。

### 4.2 添加站点时的标题与图标

当你保存一个网址，应用会向该地址请求公开 HTML，并可能再请求图标文件，以便生成桌面入口。目标站点（及其 CDN）会按他们的规则看到这次请求。

### 4.3 检查更新

仅在你于「设置 → 检查新版本」点按后，应用会对

`https://api.github.com/repos/AIMFllyYS/PocketWebShell/releases/latest`

发送 HTTPS GET。请求**不附带**浏览历史、Cookie 或账号。HTTPS 仍会携带 IP、粗略网络位置、User-Agent 等传输层信息。接收方是 GitHub。维护者**没有**自建更新服务器。你可以选择不去点检查。

从官网或 GitHub Release 下载 APK，同样是你主动访问 GitHub。

## 5. 系统权限

权限只在对应功能需要时申请，不会在同意本规则时一揽子打开。

| 权限 | 用途 | 拒绝之后 |
|---|---|---|
| 网络 | 打开网页、抓取标题/图标、检查更新 | 无法访问远程网站 |
| 通知 | 前台服务保活提示、下载进度 | 保活通知不可用，基本浏览仍可用 |
| 忽略电池优化 | 尽量减少系统杀掉保活会话 | 会话更容易被回收 |
| 相机 / 麦克风 / 位置 | 仅当网页或系统选择器提出请求，且你在系统对话框中允许 | 该网页的该项功能不可用 |
| 存储 / 所有文件（侧载列举本机 HTML） | 在应用内选择本机 HTML 文件 | 该导入功能不可用；已保存的入口仍可打开 |

「所有文件」权限只用于侧载场景下列举本机 HTML，不是为了读取你的相册或任意文档。当前安装包形态**不是**按 Google Play 政策准备的上架包。

前台服务通知的目的是尽量维持会话。**不能保证**后台常驻，也不能绕过系统省电、内存回收或网站自己的节流。

## 6. 第三方与系统组件

维护者未接入第一方统计、崩溃或广告 SDK。仍会用到：

- Android System WebView（由设备系统提供，可能自行更新）
- OkHttp、Coil、jsoup（添加站点、加载图标时联网）
- GitHub（更新查询与安装包分发）
- 你访问的任意网站及其第三方脚本

网页可以再加载任意远程脚本。那是网站行为，不是玄览统计。

## 7. 跨境

检查更新、访问 github.com / api.github.com，以及你打开的境外网站，都可能把请求发到中国境外。请在知情后决定是否使用这些功能。

## 8. 敏感个人信息与未成年人

精确位置、相机、麦克风只在场景化系统对话框中由你决定。应用**不是**专为不满 14 周岁儿童设计的产品。若儿童使用，请由监护人监督，并使用系统与本应用的清除、卸载能力管理本机数据。维护者在无账号模式下，通常没有一份可远程删除的「云端儿童档案」。

请不要把本规则理解成已提供青少年模式、人脸识别年龄或校园统一身份认证——那些能力**没有**做。

## 9. 你的权利（映射到本机）

在无云端副本的前提下，查阅、更正、删除主要在本机完成：

- 查看与删除站点、清除某站 Cookie 与网站存储：设置 → 存储管理
- 导出或清理应用数据：设置 → 数据管理
- 清空日志：开发者选项
- 撤回对某权限的同意：系统设置 → 应用权限
- 停止使用：卸载应用

若你曾通过 GitHub Issues 向维护者发送过邮件或附件，可以在该 Issue 中说明，维护者将按平台能力处理工单里的内容。维护者**不能**承诺删除你在第三方网站上的账号或 GitHub 自己的访问日志。

## 10. 安全措施

- 浏览数据默认留在本机
- 远程连接使用 HTTPS；打开明文 HTTP 前会单独确认
- 不静默忽略证书错误
- 不把签名密钥、口令写入仓库或日志
- 正式版 APK 可用公开证书核对签名

## 11. 规则更新

规则变更会提高本文版本与日期，并在应用「项目更新日志」和官网同步。若处理目的、方式或种类发生实质性变化，会在应用内提示你重新阅读。

继续使用检查更新、添加远程站点或打开网页，即表示你了解上述会离开本机的处理。你可以随时卸载或关闭相应权限。
